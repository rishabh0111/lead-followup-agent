# Work docs

Where this repository keeps its work documents. A skill looking for prior work searches every folder below.

| Kind | Folder |
|---|---|
| Specs | `docs/specs/` |
| Designs | `docs/designs/` |
| Plans | `docs/plans/` |
| Lessons | `docs/solutions/` |
| Codebase map | `docs/codebase/` |

The project brief predates these folders: `docs/PLAN.md` (requirements, acceptance checks, timeline) and `docs/DATA.md` (sample data spec) act as the top-level spec and plan. Read them when looking for prior work.
